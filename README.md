# Utility

General-purpose developer toolbox — a collection of everyday utilities that all run entirely in the browser. No data is ever sent to a server; everything is computed locally. **Live:** [utility.kevinprk.com](https://utility.kevinprk.com)

## Getting Started

```bash
npm install
npm run dev   # http://localhost:5173
```

## Tools

- **Hash Generator** — compute MD5, SHA-1, SHA-256, and SHA-512 hashes of any text; all hashed client-side with no network request
- **Base64** — encode or decode text to/from Base64, or convert any file to a Base64 data URI
- **Regex Tester** — write a regex pattern and see live match highlighting in the test string; shows capture groups and match positions
- **JSON Prettifier** — paste JSON to format it with syntax highlighting, validate it for errors, or minify it back to one line
- **YAML ↔ JSON** — convert between YAML and JSON in both directions; useful when switching between config formats
- **String Transformer** — convert text between camelCase, snake_case, kebab-case, PascalCase, SCREAMING_SNAKE_CASE, and more
- **HAR Analyzer** — upload a Chrome or Firefox `.har` file to inspect request waterfall, timing breakdowns, response sizes, and headers
